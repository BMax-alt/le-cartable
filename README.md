# Le Cartable

Flashcards de révision pour le CM2 sur iPad : la réponse s'écrit à l'Apple Pencil sur une page Seyès, puis l'enfant retourne la carte et s'auto-évalue.

- `index.html` : l'app (ne change pas d'une semaine à l'autre)
- `decks.js` : les paquets de cartes, mis à jour chaque semaine

Projet suivi dans le vault : `PERSPECTIVE_IA/01_PROJECTS/APP_REVISIONS/`.
