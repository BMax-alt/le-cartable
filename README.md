# Le Cartable

Flashcards de révision pour le CM2 sur iPad : la réponse s'écrit à l'Apple Pencil sur une page Seyès. Questionnaires et résultats (maths, dictée) corrigés par l'app, le reste en auto-évaluation.

- `index.html` : l'app, seul fichier public.
- Les paquets, le cours et la progression vivent dans un dépôt **privé** (le coffre). L'app y accède avec une clé limitée à ce dépôt, saisie une fois dans les Réglages de l'iPad. Aucune donnée ni aucun contenu de cours ici.

Projet suivi dans le vault : `PERSPECTIVE_IA/01_PROJECTS/APP_REVISIONS/`.
